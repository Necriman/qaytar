# Qaytar — возврат 12% за контракт, школу и ипотеку

```
qaytar/
├── bot/            Telegram-бот @QaytarStartupBot (Python, aiogram 3 + Gemini)
│   ├── bot.py      все сценарии бота
│   ├── texts.py    все тексты (узб./рус.) и статьи — правьте здесь
│   ├── calc.py     расчёт суммы возврата
│   ├── ai_check.py проверка документов через Gemini (без сохранения)
│   ├── db.py       SQLite (без документов)
│   └── .env        СЕКРЕТЫ: токен и ключ. Никому не показывать и не загружать в GitHub
├── site/           лендинг + privacy.html + terms.html (статический, без сборки)
└── assets/         bot_avatar.png и скрипт картинок
```

## 1. Запуск бота (5 минут)

```powershell
cd qaytar\bot
pip install -r requirements.txt
python bot.py
```

Бот работает, пока открыт этот терминал. Для хакатона достаточно ноутбука с интернетом.

**Сразу сделайте в `.env`:**
- `ADMIN_IDS` — ваш Telegram ID (узнать у @userinfobot). Без него не придут уведомления о бронях и чеки, и не будет работать `/stats`.
- `PAYMENT_CARD` и `PAYMENT_HOLDER` — карта **совершеннолетнего** (родителя или участника команды старше 18 лет).
- `SITE_URL` — адрес сайта после публикации (ссылки на политику в боте ведут туда).

## 2. Что умеет бот
| Кнопка | Что делает |
|---|---|
| ✅ Проверить право | 5 вопросов → сумма возврата (с лимитом по удержанному налогу) + эффект 🎉 |
| 📄 Проверить документы | С ИИ: фото договора/чеков → Gemini читает ФИО, суммы, даты → отчёт об ошибках. Без ИИ: 6 вопросов |
| 🧭 Инструкция | 7 шагов по приложению Soliq с кнопками «Назад/Далее» |
| 🤝 Подать вместе | Бронь: имя, телефон, формат → реквизиты для оплаты → чек уходит админу → кнопка «оплата подтверждена» |
| 📚 Статьи | 6 статей (кто может, ошибки, сад/школа, ипотека, сроки, мошенники) |
| ⏰ Напоминания | 5 января, 1 марта, 25 марта |
| 🔒 Конфиденциальность | Политика + удаление всех данных пользователя |

**Команды админа:** `/stats` — пользователи, сколько денег «нашли» людям, брони и оплаты (цифры для питча!), `/broadcast текст` — рассылка всем.

## 3. Стикеры и премиум-эмодзи
- **Стикеры:** напишите боту любой стикер с аккаунта админа — он ответит его `file_id`. Вставьте в `.env` → `STICKER_WELCOME`, `STICKER_SUCCESS`, `STICKER_DOCS`.
- **Эффекты сообщений** (🎉🔥👍 анимация) уже включены: на результате расчёта, брони и успешной проверке.
- **Премиум-эмодзи в тексте:** Telegram разрешает их ботам только при покупке доп. юзернейма на Fragment. Без этого они показываются как обычные эмодзи. Бот покажет их ID, если прислать ему премиум-эмодзи.
- **Аватар бота:** @BotFather → `/setuserpic` → ваш логотип (или `assets/bot_avatar.png`).

## 4. Публикация сайта (бесплатно)
1. Самое быстрое: https://app.netlify.com/drop → перетащите папку `site` → получите ссылку.
2. Или GitHub Pages: загрузите содержимое `site/` в репозиторий → Settings → Pages.
3. Если домен будет не `qaytar.uz`, замените `https://qaytar.uz` на свой адрес во всех файлах `site/` (index, privacy, terms, robots.txt, sitemap.xml) и в `.env` (`SITE_URL`).
4. Google: https://search.google.com/search-console → добавьте сайт → отправьте `sitemap.xml`.

## 5. Юридический чек-лист (обязательно до реальных пользователей)
- [ ] Вписать данные **Оператора** вместо `[...]` в `privacy.html` и `terms.html`. Оператор — совершеннолетнее лицо (родитель / ИП / ООО), не несовершеннолетний.
- [ ] **Gemini:** на бесплатном тарифе Google может использовать присланные данные для улучшения своих продуктов (и их могут просматривать люди). Перед тем как принимать **реальные** документы, включите оплату (Paid tier) в Google AI Studio — стоимость проверки одного фото доли цента. Или выключите ИИ: оставьте `GEMINI_API_KEY` пустым — бот перейдёт на проверку вопросами.
- [ ] Уточнить у юриста: нужна ли регистрация базы персональных данных в госреестре и подходит ли формат «технической помощи» под требования Закона «О налоговом консультировании».
- [ ] Чеки об оплате брони удалять из чата админа после подтверждения (так написано в политике).
- [ ] Сервер для постоянной работы: укажите провайдера и страну в `privacy.html`, раздел 5.

## 6. Безопасность
- `.env` в `.gitignore`. Если токен где-то утёк — @BotFather → `/revoke`.
- Бот никогда не просит пароли/ЭЦП/SMS-коды — не добавляйте такие функции.
